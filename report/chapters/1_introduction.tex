\section{Introduction}
\label{sec:introduction}

\subsection{Motivation}

The classic World Wide Web links documents: a page about an entity
points to another page, and a reader follows the links. Machines can follow
them too, but they cannot interpret them. The Semantic Web addresses this gap
by publishing data as entities and relations rather than pages: facts
are expressed as RDF triples, so a computer can combine data about the same
thing across independent sources \cite{rdf11, fivestar}. For example, our graph
states that the Negroni has base spirit gin; Wikidata carries an item for the
same cocktail; once the two identifiers are connected with
\texttt{owl:sameAs}, a single query can use both datasets.

This project applies those ideas to the world of drinks: cocktails, the
ingredients and measures they use, the spirits and brands behind them, and the
distilleries that produce those brands. The domain was chosen deliberately. The
data is available in machine-readable form: TheCocktailDB exposes a free
JSON API \cite{cocktaildb} and Wikidata covers distilleries with coordinates
\cite{wikidata}. The entities are already present in existing Linked Open
Data (LOD) datasets, which makes five-star linking realistic \cite{dbpedia},
and the results are easy to inspect: ingredient lists, measures and maps make
the application demonstrable rather than abstract.

\subsection{Objectives}

Following the five course requirements, the project delivers:

\begin{enumerate}[label=(\arabic*), itemsep=2pt]
  \item an OWL~2 ontology (\emph{DrinkOnto}) that defines the classes and
        properties of the domain;
  \item a collection pipeline that gathers cocktail data from
        public sources and records their provenance;
  \item a transformation that emits the collected data as RDF in a
        non-proprietary W3C format (four-star);
  \item an interlinking step that links our entities with Wikidata and
        DBpedia through \texttt{owl:sameAs} (five-star);
  \item a query interface: a SPARQL endpoint with a small query UI and eleven
        curated demonstration queries.
\end{enumerate}

\subsection{Contributions}

The main contributions of the project are the following:

\begin{itemize}[itemsep=2pt]
  \item a compact OWL~2 ontology, DrinkOnto, that keeps measures queryable by
        reifying each ingredient usage as an \texttt{IngredientAmount} node,
        and derives \texttt{hasIngredient} through a property chain, showing
        OWL constructs beyond plain subclassing;
  \item a reproducible pipeline for collecting, transforming and interlinking
        the data, with cached downloads, a SHA-256 provenance manifest,
        deterministic URIs and two quality gates, so that every reported result
        can be regenerated from the repository;
  \item a precision-oriented interlinking workflow with an explicit evaluation
        protocol: exact-label matching, description scoring, and a seeded
        hand-checked sample of links whose failure modes are reported rather
        than hidden;
  \item a portable query interface with dereferenceable URIs and eleven
        curated queries, verified unchanged on both rdflib and Apache Jena
        Fuseki \cite{jena}.
\end{itemize}
