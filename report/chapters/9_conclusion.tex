\section{Conclusion}
\label{sec:conclusion}

This project built a five-star Linked Open Data application for the domain of
cocktails, spirits and distilleries, and documented every step from raw web
data to a queryable knowledge graph. The OWL~2 ontology \emph{DrinkOnto}
models cocktail recipes with a measure-aware \texttt{IngredientAmount} node and
derives \texttt{hasIngredient} through a property chain, so quantitative
questions such as ``how much lemon is in a Whiskey Sour?'' are answered without
inflating the schema. A reproducible pipeline collected 441 cocktails from
TheCocktailDB and 865 distilleries plus 12 spirit brands from Wikidata,
transformed them into roughly 22{,}300 triples, and reconciled the entities with
Wikidata and DBpedia, yielding 1{,}220 Wikidata links and 390 DBpedia links.
The merged graph is served by a zero-install SPARQL endpoint with a query UI
and dereferenceable URIs, and the eleven demonstration queries were verified
unchanged on Apache Jena Fuseki.

Beyond the deliverables themselves, the project produced evidence that can be
checked rather than believed: a provenance manifest with hashes for every
source dump, deterministic identifiers that make every count reproducible, a
seeded sample for measuring link precision, and captured query outputs for both
query engines. The main shortcomings (limited cocktail recall, the
base-spirit heuristic, sparse brand coverage) are measured and documented in
Section~\ref{sec:evaluation}, together with concrete routes to improve them. All components can be
re-run from the public repository in a few commands, which is the practical
meaning of the fifth star: data that is not only open, but linked, testable and
reusable.
