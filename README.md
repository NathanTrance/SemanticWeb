# linked-drinks (working title)

5-star Linked Open Data for **cocktails, spirits & distilleries** — a Semantic Web / LOD
capstone (Masters, Hanoi University of Science and Technology, Project 1).

Status: planning. See [`PLANNING.md`](PLANNING.md) for the full project plan (ontology,
data sources, pipeline, linking, timeline), and [`AGENT.md`](AGENT.md) for repo working
agreements. The stack: RDF / RDF-S / OWL / SPARQL, Python + RDFlib, Apache Jena Fuseki,
Protégé, OpenRefine reconciliation, optional Silk.

## Deliverables
- Slide deck, report (≤15 pages), video (3–5 min) — the 5★ journey from raw data to a
  queryable, linked knowledge graph.
